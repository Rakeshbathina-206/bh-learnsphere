# BH LearnSphere (Skeleton)

## Stack
- Backend: Java Spring Boot
- Frontend: React
- Database: MySQL

## Quick start

### Backend
1. Configure database in backend/src/main/resources/application.properties or use env:
   - `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD`
2. Run:
```bash
cd backend
./mvnw spring-boot:run   # or mvn spring-boot:run
